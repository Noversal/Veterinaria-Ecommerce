# 🛒 Veterinaria-Ecommerce

Proyecto colaborativo de una tienda online desarrollada con **HTML, CSS y JavaScript Vanilla**.  
La aplicación permite navegar productos, gestionar un carrito de compras y simular una experiencia básica de compra desde el navegador.

---

## 📌 Características

- Visualización dinámica de productos
- Carrito de compras
- Persistencia de datos con `LocalStorage`
- Diseño responsive
- Buscador de productos
- Interfaz desarrollada completamente en JavaScript Vanilla
- Botones de agregar al carrito y quitar del carrito
- Modal de detalle de productos
- Notificaciones visuales

---

## 🚀 Tecnologías utilizadas

- HTML5
- Bootstrap 5.3.3 y CSS3 
- JavaScript Vanilla

---

## ▶️ Ejecución del proyecto

### 1. Clonar el repositorio

```bash
git clone https://github.com/noversal/Veterinaria-Ecommerce.git
cd Veterinaria-Ecommerce
````

### 2. Levantar un servidor local

```bash
npx live-server
```

### 3. Abrir el proyecto en el navegador

El servidor abrirá automáticamente el proyecto en el navegador.
En caso contrario, acceder manualmente a:

```txt
http://127.0.0.1:8080
```
